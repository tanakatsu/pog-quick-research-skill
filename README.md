# pog-quick-research-skill

POG（ペーパーオーナーゲーム）の馬検討を支援する Claude Code スキル集です。

## 概要

netkeiba の掲示板コメントや馬情報を自動収集し、POG指名候補馬のレポート作成や事後検証を行うスキルを提供します。

## 前提条件

- [Claude Code](https://claude.ai/code)
- Python 3.x
- [uv](https://docs.astral.sh/uv/)

## 事前準備

リポジトリをクローン後、セットアップスクリプトを実行してシンボリックリンクの作成と依存関係のインストールを行います。

```bash
bash setup.sh
```

## スキルの説明

### `/pog-horse-report` — 馬レポートの作成

POG指名候補馬の情報を収集し、指名判断に役立つレポートを作成します。

**レポートの内容**
- 基本情報
- 近況（時系列）
- ポジティブな評価
- ポジティブな評価に含まれる潜在的リスク
- ネガティブ・懸念点
- 総評

**使用例**
```
/pog-horse-report ラッキースパークル
```

---

### `/pog-bitter-lesson` — 事後検証レポートの作成

期待ほど活躍できなかった馬についてポストモーテムを行い、見落としていた不安のサインを分析します。

**レポートの内容**
- 基本情報
- ポジティブな客観的コメント
- 不安要素・ネガティブな客観的コメント（後から見れば「サイン」だったもの）
- 総合分析：隠れていた不安のサイン
- 結論

**使用例**
```
/pog-bitter-lesson グランマエストロ
```

## 利用可能なスクリプト

| スクリプト | 説明 |
|---|---|
| `scripts/get_horse_id.py` | 馬名または母馬名から馬IDを取得 |
| `scripts/get_horse_info.py` | 馬IDから基本情報を取得 |
| `scripts/get_board_comments.py` | 馬IDから掲示板コメントを取得 |
| `scripts/get_breeding_performance.py` | 母馬IDから繁殖成績を取得 |
| `scripts/filter_comments.py` | 掲示板コメントを日付範囲でフィルタリング |
