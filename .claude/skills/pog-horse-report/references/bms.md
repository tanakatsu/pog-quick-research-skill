# POG向き、不向きの母父

## POG向きの母父

| 母父               | 評価  | 主な理由                              |
| ---------------- | --- | --------------------------------- |
| ディープインパクト        | 最優先 | 瞬発力・芝適性・完成度を補強。どの種牡馬とも相性良く「外しにくい」 |
| キングカメハメハ         | 最優先 | スピード＋パワー補完で早期勝ち上がり率が高い            |
| ハーツクライ           | 上位  | 成長力と底力を付与。キズナ・エピファと好相性            |
| Storm Cat系       | 上位  | 早熟スピード強化。短距離〜マイルでPOG即戦力           |
| Galileo          | 上位  | 欧州的スタミナ＋日本芝適性。クラシック向き             |
| ダイワメジャー          | 上位  | 早熟性が高く2歳戦から動ける                    |
| クロフネ             | 上位  | パワー・ダート適性補完だが芝でも安定感あり             |
| フレンチデピュティ        | 中位  | スピード＋持続力。芝ダート両対応で安定               |
| マンハッタンカフェ        | 中位  | 中距離適性・底力補強でクラシック向き                |
| シンボリクリスエス        | 中位  | パワー・持続力型。エピファ系と特に相性良し             |
| アグネスタキオン         | 中位  | 瞬発力・完成度補強。やや古いが依然有効               |
| Unbridled’s Song | 中位  | スピード補強で早期始動しやすい                   |

## POGに不向き・慎重にしたい母父

| 母父                                | 評価  | 主な理由                   |
| --------------------------------- | --- | ---------------------- |
| ステイゴールド                           | 慎重  | 晩成・スタミナ型でPOG期間に間に合いにくい |
| ゴールドシップ                           | 慎重  | 同様に晩成傾向が強い             |
| ロベルト系（濃い血統）                       | 慎重  | パワー型・成長型で早期始動に不安       |
| メジロマックイーン                         | 慎重  | スタミナ型でスピード不足になりやすい     |
| ブライアンズタイム                         | 慎重  | パワー型で軽い芝の瞬発戦に弱い        |
| タニノギムレット                          | 慎重  | 気性・ムラの影響で安定感に欠ける       |
| シンボリルドルフ                          | 慎重  | 古い血統でスピード不足傾向          |
| サンデーサイレンス直仔（高齢牝馬）                 | 慎重  | 繁殖年齢によるリスクが大きい         |
| ダート色の強い米国血統（Deputy Minister濃い系など） | 不向き | 芝クラシックへの適性が弱くなりやすい     |
| 欧州重厚血統（Sadler’s Wells濃すぎ）         | 慎重  | 晩成・重馬場型に寄りやすい          |
