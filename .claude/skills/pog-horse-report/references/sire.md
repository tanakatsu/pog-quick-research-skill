# POGに向き、不向きな種牡馬

## POG向きの種牡馬

| 種牡馬       | 評価   | 主な理由                                 |
| --------- | ---- | ------------------------------------ |
| エピファネイア   | 最優先  | 2歳リーディング上位常連。早期始動＋クラシック適性のバランスが非常に高い |
| キズナ       | 最優先  | 総合リーディング上位かつ2歳戦でも安定。完成度が高くPOG向き      |
| サートゥルナーリア | 最優先  | 2歳戦で即結果。初年度から早熟性＋スピードを証明             |
| コントレイル    | 上位候補 | 産駒数・良血多く大物期待。POGで主役級になりやすい           |
| モーリス      | 上位候補 | 勝ち上がり率が高く、2歳戦から安定して稼げる               |
| キタサンブラック  | 上位候補 | 大物輩出力が高い。クラシック狙いの軸になる存在              |
| リアルスティール  | 上位候補 | 2歳戦で結果あり。人気しすぎず妙味あり                  |
| ロードカナロア   | 安定枠  | マイル〜中距離で安定。牝馬・良血なら特に有力               |
| リオンディーズ   | 中位   | 勝ち上がり＋重賞狙いのバランス型                     |
| レイデオロ     | 中位   | 徐々に成績上昇。良血・厩舎込みで狙うタイプ                |
| シルバーステート  | 中位   | 早期始動タイプ多く、勝ち上がり狙いに向く                 |
| ルヴァンスレーヴ  | 条件付き | ダートPOGなら有力（芝中心POGでは優先度低）             |
| ナダル       | 条件付き | ダート短距離〜マイルで早期活躍                      |
| モズアスコット   | 条件付き | ダート・短距離でポイント加算可能                     |

## POG不向きの種牡馬・慎重にしたい種牡馬

| 種牡馬           | 評価  | 主な理由                   |
| ------------- | --- | ---------------------- |
| ゴールドシップ       | 慎重  | 晩成・スタミナ型でPOG期間に間に合いにくい |
| ルーラーシップ       | 慎重  | 成長力型で2歳〜3歳春の即効性に欠ける    |
| ハービンジャー       | 慎重  | 個体差大きく、POGでは安定しない      |
| オルフェーヴル       | 慎重  | 爆発力あるがムラが大きくリスク高い      |
| ホッコータルマエ      | 不向き | ダート専色が強く芝クラシックに繋がりにくい  |
| シニスターミニスター    | 不向き | ダート短距離中心でPOG向きでない      |
| パイロ           | 不向き | ダート寄りで芝重賞期待が低い         |
| ダノンレジェンド      | 不向き | 地方・ダート中心でPOGとの相性が悪い    |
| アジアエクスプレス     | 不向き | ダート短距離寄り               |
| マジェスティックウォリアー | 不向き | ダート型で芝クラシック不向き         |
| カリフォルニアクローム   | 不向き | ダート寄り・芝大物が少ない          |
| サトノダイヤモンド     | 慎重  | 期待値ほどPOGでの安定感がない       |
| アルアイン         | 慎重  | 決め手不足で上位指名にはやや弱い       |
| ブリックスアンドモルタル  | 慎重  | 日本適性・安定感ともにまだ不透明       |
