# 関係者コメント（調教師・助手・クラブコメント）の読み取り方

## 走る馬を見抜く「勝ちコメント」

| コメント例                | 評価  | 意味・理由               | POGでの解釈        |
| -------------------- | --- | ------------------- | -------------- |
| 「仕上がりが早い」「もう動ける」     | 最優先 | 早期完成型。2歳夏〜秋で即デビュー可能 | 即ポイント加算候補（超重要） |
| 「乗り込み量が豊富」「順調に進んでいる」 | 最優先 | トラブルなく育成が進んでいる      | デビュー遅延リスクが低い   |
| 「調教で古馬と互角以上」         | 最優先 | 能力がすでに高い            | 重賞級ポテンシャルあり    |
| 「反応が良い」「切れがある」       | 最優先 | 日本芝で重要な瞬発力タイプ       | クラシック向き        |
| 「操縦性が高い」「レースセンスが良い」  | 上位  | 気性が安定し崩れにくい         | 勝ち上がり率が高い      |
| 「完成度が高い」             | 上位  | 若い時点で能力が出せる         | POG期間に直結       |
| 「軽い走り」「スピードがある」      | 上位  | 芝適性＋スピード型           | マイル〜中距離で期待     |
| 「ゲートが速い」             | 上位  | 実戦で有利               | 未勝利戦で取りこぼしにくい  |
| 「気性が前向き」             | 上位  | レースに行く気がある          | 初戦から結果出やすい     |
| 「距離はマイル〜中距離」         | 上位  | クラシック適性あり           | ダービー・オークス路線    |

## 要注意「危険コメント」（人気馬でも飛ぶ）

| コメント例             | 評価 | 意味・理由      | POGでのリスク         |
| ----------------- | -- | ---------- | ---------------- |
| 「まだ緩い」「これから良くなる」  | 危険 | 未完成・晩成     | デビュー遅れる or 取りこぼし |
| 「成長を待ちたい」         | 危険 | 仕上がり遅い     | POG期間に間に合わない     |
| 「体質が弱い」「慎重に進めている」 | 危険 | 故障リスク・調整遅れ | 出走数が少ない          |
| 「気性に課題」           | 危険 | 折り合い・制御難   | 能力あっても負ける        |
| 「大型でゆっくり」         | 危険 | 成長型・晩成     | 3歳春に間に合わない可能性    |
| 「トモが緩い」           | 危険 | 後肢の力不足     | 加速力不足・完成遅れ       |
| 「まだ動ききれない」        | 危険 | 調教で動けない    | 初戦取りこぼしやすい       |
| 「芝・ダートどちらも試す」     | 危険 | 適性不明       | 迷走してポイント取り逃す     |
| 「距離は長めが良さそう」      | 危険 | スタミナ型      | 早期重賞に間に合いにくい     |
| 「一度使ってから」         | 危険 | 叩き良化型      | 初戦負け→機会損失        |

## グレー（判断が分かれるコメント）

| コメント例        | 評価  | 意味・理由     | 判断ポイント      |
| ------------ | --- | --------- | ----------- |
| 「素質は高い」      | 要精査 | 抽象的で裏付けなし | 調教時計とセットで判断 |
| 「大物感がある」     | 要精査 | 主観コメント    | 厩舎・血統が伴うか確認 |
| 「ゆったり成長」     | 要精査 | 晩成寄り      | POGでは割引     |
| 「まだ良くなる余地あり」 | 要精査 | 未完成       | デビュー時期を確認   |
| 「フォームがいい」    | 要精査 | 基礎能力はある   | 実戦スピードと別問題  |

## 実戦で使える「コメントの読み方テンプレ」

### ◎ 即指名レベル（勝ちパターン）

- 「仕上がり早い」＋「調教動く」＋「反応良い」

👉 → ほぼ当たり候補

### ◎ 上位指名（クラシック狙い）

- 「切れがある」＋「中距離向き」＋「順調」

👉 → G1候補

### ⚠️ 回避すべきパターン

- 「まだ緩い」＋「成長待ち」＋「大型馬」

👉 → ほぼPOG負けパターン


## 一番重要な本質（差がつくポイント）

- コメントは「ポジティブか」ではなく 👉 “具体性があるか”で判断する
- 「良い馬」より 👉 “いつ使える馬か”が重要
- 強い馬のコメントは 👉 シンプルで断定的（＝迷いがない）
