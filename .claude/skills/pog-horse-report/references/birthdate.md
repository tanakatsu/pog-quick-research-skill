# 生年月日によるPOG診断ポイント

## 理想：1月〜2月生まれ

| 生年月日 | 評価  | 理由            | POGでの強み     |
| ---- | --- | ------------- | ----------- |
| 1月前半 | 最優先 | 身体成熟が最も早い     | 2歳夏デビューしやすい |
| 1月後半 | 最優先 | 完成度が高い        | 早期重賞向き      |
| 2月前半 | 最優先 | 早熟＋成長余地のバランス良 | クラシック直結     |
| 2月後半 | 上位  | 十分早い          | 王道POGゾーン    |

## 良い：3月生まれ

| 生年月日 | 評価 | 理由        | POGでの強み  |
| ---- | -- | --------- | -------- |
| 3月前半 | 上位 | 平均以上の完成度  | 勝ち上がりやすい |
| 3月後半 | 上位 | まだ十分POG向き | 秋以降伸びる   |

## 普通：4月生まれ

| 生年月日 | 評価   | 理由       | POGでの特徴 |
| ---- | ---- | -------- | ------- |
| 4月前半 | 普通   | 標準的      | 血統・厩舎次第 |
| 4月後半 | やや慎重 | 成熟差が出始める | 早期戦で不利  |

## 注意：5月以降生まれ

| 生年月日 | 評価 | 理由         | POGでのリスク       |
| ---- | -- | ---------- | -------------- |
| 5月前半 | 慎重 | 身体が幼いケース多い | 夏競馬間に合わない      |
| 5月後半 | 危険 | 完成が遅い      | デビュー遅延         |
| 6月以降 | 危険 | かなり不利      | POG期間に完成しない可能性 |

## なぜ早生まれが有利なのか？

### 競走馬は「全馬1月1日生まれ扱い」

| 実際の月齢差         | 2歳6月時点の差  |
| -------------- | --------- |
| 1月生まれ vs 5月生まれ | 約4か月差     |
| 人間換算           | 約2〜3年差レベル |

👉 かなり大きい

### 2歳戦は“完成度勝負”

早期重賞では👇が重要

- 筋肉量
- 骨格完成
- 心肺機能
- 気性成熟

👉 早生まれが圧倒的有利

### ノーザン系育成と相性抜群

近年のPOG勝ち馬は

- 1〜2月生まれ
- ノーザン育成
- 夏デビュー

が非常に多い。

## “走る早生まれ”の理想パターン

| 条件      | 理由       |
| ------- | -------- |
| 1〜2月生まれ | 完成早い     |
| 王道種牡馬   | 早期始動しやすい |
| ノーザン系   | 育成高速     |
| 上位厩舎    | 夏デビュー可能  |
| トモ大きい   | さらに即戦力   |

## “危険な遅生まれ”パターン

| 条件         | 理由     |
| ---------- | ------ |
| 5月以降       | 身体未成熟  |
| 晩成血統       | さらに遅れる |
| 大型馬        | 成長待ち   |
| 「まだ緩い」コメント | ほぼ危険信号 |

👉 人気でも飛びやすい

## 例外（遅生まれでも走る馬）

以下なら遅生まれでも買える👇

| 条件         | 理由            |
| ---------- | ------------- |
| キタサンブラック産駒 | 成長力型でも間に合うケース |
| エピファネイア産駒  | 秋以降急成長あり      |
| ノーザン天栄超評価馬 | 育成力でカバー       |
| 調教抜群       | 能力で成熟差を超える    |

## 実戦テンプレ（超重要）

### ◎ ドラフト上位で狙う

- 1〜2月生まれ
- 王道血統
- ノーザン
- 上位厩舎

👉 まず外れない

### ◎ 穴で狙う

- 3月生まれ
- コメント強気
- 馬体完成度高い

### ⚠️ 切る基準

- 5月生まれ
- 晩成コメント
- 緩い馬体

👉 人気でも消し候補
