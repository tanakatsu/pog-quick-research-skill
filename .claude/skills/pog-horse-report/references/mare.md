# POGで活躍しやすい母馬の特徴

## 活躍馬を出す母馬の特徴（競走成績）

| 項目                 | 評価  | 内容            | POGでの見方                   |
| ------------------ | --- | ------------- | ------------------------- |
| G1勝利               | 最優先 | 自身がG1馬        | 「クラシック直結」最強パターン。迷わず上位指名候補 |
| G1連対・重賞勝ち          | 最優先 | G1で好走 or 重賞勝利 | 成功率が非常に高い。POG向け鉄板ゾーン      |
| 芝中距離実績（1600〜2400m） | 最優先 | クラシック距離で好走    | ダービー・オークス直結。最重要適性         |
| 2歳戦で活躍             | 上位  | 早期デビュー＋勝利     | 産駒も早熟傾向になりやすい             |
| 瞬発力型（上がり最速経験）      | 上位  | 切れ味勝負に強い      | 日本芝で極めて重要                 |
| 複数勝利（3勝以上）         | 上位  | 安定した競走能力      | 再現性が高くハズレにくい              |
| 海外G1実績             | 上位  | 欧州・米国G1       | スタミナ・底力補強でクラシック向き         |

## 注意すべき母馬（競走成績）

| 項目            | 評価 | 内容         | POGでのリスク      |
| ------------- | -- | ---------- | ------------- |
| 未勝利・1勝止まり     | 慎重 | 自身の競走能力が低い | 血統頼みで再現性が低い   |
| ダート専用実績       | 慎重 | ダートでのみ好走   | 芝クラシックに繋がりにくい |
| 短距離特化（〜1200m） | 慎重 | スプリント型     | 距離不足でクラシック不向き |
| 晩成型（古馬で覚醒）    | 慎重 | 成長が遅い      | POG期間に間に合わない  |
| 出走数少ない（虚弱）    | 慎重 | キャリア不足     | 体質リスクが遺伝する可能性 |

## 活躍馬を出す母馬の特徴（繁殖成績）

| 項目         | 評価  | 内容        | POGでの見方      |
| ---------- | --- | --------- | ------------ |
| 既に重賞馬を輩出   | 最優先 | 兄姉に重賞勝ち馬  | 「再現性あり」＝最強指標 |
| 勝ち上がり率が高い  | 最優先 | 複数頭が勝利    | 安定して当たりを出す母  |
| 連続して活躍馬を出す | 最優先 | 2頭以上がOP以上 | “当たり繁殖”確定    |
| 初仔〜3番仔     | 上位  | 若い繁殖期     | 体力・質が高い時期    |
| 父が変わっても走る  | 上位  | 異なる種牡馬で成功 | 母の能力が高い証拠    |
| ノーザン系繁殖    | 上位  | 管理・育成が優秀  | POG成功率が高い    |

## 注意すべき繁殖パターン

| 項目            | 評価  | 内容       | POGでのリスク   |
| ------------- | --- | -------- | ---------- |
| 産駒が未勝利続き      | 不向き | 勝ち上がりゼロ  | 明確に“ハズレ繁殖” |
| 高齢繁殖（10歳後半〜）  | 慎重  | 繁殖能力低下   | 体質・成長に影響   |
| 初仔            | 慎重  | データ不足    | 当たり外れが大きい  |
| 兄姉がダート専用      | 慎重  | 芝実績なし    | クラシック適性不安  |
| 間隔空きすぎ（不受胎多い） | 慎重  | 生産リズム不安定 | 体質リスクあり    |

## POGで勝つための“母馬チェックテンプレ”

### ◎ 最強パターン

- 母：重賞勝ち or G1好走
- 兄姉：勝ち上がり or OPクラス
- 芝1600〜2400m実績
- 繁殖年齢：若い（〜10歳前後）

👉 これだけで“ドラフト上位確定”

### ◎ 次点パターン（穴）

- 母：3勝クラス以上
- 兄姉：1勝以上複数
- 初仔 or 2番仔

👉 人気薄でも期待値高い

### ⚠️ 危険パターン

- 未勝利母 × 未勝利兄姉
- ダート母 × ダート兄姉
- 高齢繁殖 × 晩成血統

👉 POGではほぼ回避推奨
