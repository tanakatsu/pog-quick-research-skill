# 馬体チェック方法

## POGで走る馬の馬体チェック方法（良い馬）

### 全体バランス

| チェック項目        | 評価  | 理由            | 見るポイント     |
| ------------- | --- | ------------- | ---------- |
| 前後のバランスが良い    | 最優先 | 推進力が効率よく伝わる   | 前脚と後脚の位置関係 |
| 胴の長さが適度       | 最優先 | スピードと持続力のバランス | 短すぎず長すぎず   |
| 首・胴・トモの流れが滑らか | 最優先 | 無駄のない動きになる    | “一直線のライン”  |

### トモ（後肢）

| チェック項目   | 評価  | 理由          | 見るポイント   |
| -------- | --- | ----------- | -------- |
| トモが大きく丸い | 最優先 | 推進力の源（エンジン） | お尻のボリューム |
| 横幅がある    | 最優先 | パワーと加速力     | 横から見た厚み  |
| 筋肉の張りが良い | 上位  | 仕上がりが早い     | 張り・ツヤ    |

### 胸・肩まわり

| チェック項目    | 評価  | 理由        | 見るポイント  |
| --------- | --- | --------- | ------- |
| 胸が深い      | 最優先 | 心肺能力が高い   | 前から見た厚み |
| 肩の角度が寝ている | 最優先 | ストライドが伸びる | 斜めのライン  |
| 前躯がしっかり   | 上位  | スピードに直結   | 前脚の付け根  |

### 脚・立ち姿

| チェック項目 | 評価  | 理由        | 見るポイント   |
| ------ | --- | --------- | -------- |
| 脚がまっすぐ | 最優先 | 故障リスクが低い  | 正面・横から確認 |
| 蹄がしっかり | 上位  | 地面を捉える力   | 小さすぎない   |
| 立ち姿が安定 | 上位  | バランス能力が高い | ブレない姿勢   |

### 皮膚・毛ヅヤ

| チェック項目 | 評価 | 理由        | 見るポイント  |
| ------ | -- | --------- | ------- |
| 毛ヅヤが良い | 上位 | 健康状態が良い   | 光沢感     |
| 皮膚が薄い  | 上位 | 仕上がりが早い   | 血管が浮く感じ |
| 張りがある  | 上位 | コンディション良好 | たるみがない  |

## POGで走らない馬の特徴（危険馬体）

### バランスが悪い

| チェック項目    | 評価 | 理由      | リスク      |
| --------- | -- | ------- | -------- |
| 前後どちらかが弱い | 危険 | 力が伝わらない | 伸びない     |
| 胴が長すぎる    | 危険 | スピード不足  | 晩成になりやすい |
| 全体が緩い     | 危険 | 未完成     | デビュー遅れ   |

### トモが弱い

| チェック項目 | 評価 | 理由     | リスク    |
| ------ | -- | ------ | ------ |
| トモが薄い  | 危険 | 推進力不足  | 加速できない |
| 平たい    | 危険 | パワー不足  | 直線伸びない |
| 張りがない  | 危険 | 仕上がり遅い | 未勝利で苦戦 |

### 脚の問題

| チェック項目       | 評価 | 理由      | リスク    |
| ------------ | -- | ------- | ------ |
| 内向・外向（脚が曲がる） | 危険 | 負担が偏る   | 故障リスク  |
| 繋ぎが寝すぎ/立ちすぎ  | 危険 | クッション不良 | ケガしやすい |
| 細すぎる脚        | 危険 | 耐久力不足   | 使えない   |

### 典型的な“POG地雷馬”

| 特徴        | 理由         | 結果           |
| --------- | ---------- | ------------ |
| 大型で緩い     | 晩成型        | POG期間に間に合わない |
| 良血だが筋肉不足  | 見栄えだけ      | 人気倒れ         |
| トモ弱いディープ系 | 切れだけでパワー不足 | 未勝利沼         |
| 皮膚厚い＋重い動き | 鈍足傾向       | 重賞無理         |

## 実戦で使うチェックテンプレ

### ◎ 即指名レベル

- トモ大きい
- バランス良い
- 皮膚薄く張りあり

👉 ほぼ当たり候補

### ◎ 上位候補

- 胸深い＋肩良い
- 脚まっすぐ

👉 勝ち上がり確率高い

### ⚠️ 回避

- トモ弱い
- 緩い
- 脚悪い

👉 人気でも切るべき

## 一番重要な本質

- 「トモで8割決まる」
- 良い馬はシンプルに「力強く見える」
- 悪い馬は「どこか違和感がある」
